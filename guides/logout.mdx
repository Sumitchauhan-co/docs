Logout usually has two parts:

- Clear the local application session.
- Redirect the user to the provider logout endpoint when you want to end the provider session.

## End the local session

Clear your app cookie, server-side session, cached user data, and stored tokens.

## Redirect to provider logout

```text
https://protoauth.vercel.app/o/signout?
  id_token_hint=ID_TOKEN&
  redirect_uri=https%3A%2F%2Fapp.example.com%2Fsigned-out&
```

Validate the returned `state` after the provider redirects back to your app.

## Token revocation

Revoke refresh tokens when a user signs out of a device or disconnects an app.
