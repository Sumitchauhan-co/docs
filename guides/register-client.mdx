Register a client before your app can start an OIDC flow.

## Choose a client type

| Client type | Use for | Authentication |
| --- | --- | --- |
| Public | Browser, mobile, desktop, CLI | PKCE |
| Confidential | Server-rendered web apps and backend services | Client secret or private key |

## Configure redirect URIs

Add every callback URI your app will use.

```text
https://app.example.com
http://localhost:5173
```

The `redirect_uri` parameter must match one registered URI exactly.

## Save client settings

Store these values in your app configuration:

```bash
OIDC_ISSUER=https://auth.example.com
OIDC_CLIENT_ID=client_123
OIDC_CLIENT_SECRET=replace-me
```

<Tip>
  Public clients do not keep secrets. Use PKCE and exact redirect URI matching instead.
</Tip>
