## What you can build

- User sign-in for web, mobile, desktop, and single-page applications.
- API authorization with access tokens.
- Session renewal with refresh tokens.
- Federated logout with post-logout redirects.
- Identity-aware services that trust ID token claims.

## Base URLs

Replace the placeholder issuer with your deployment URL.

```text
Issuer: https://protoauth.vercel.app
```
