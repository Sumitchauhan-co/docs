OIDC discovery publishes provider settings at a standard URL.

```text
GET https://oidcproject-production.up.railway.app/.well-known/openid-configuration
```

## Important fields

| Field | Description |
| --- | --- |
| `issuer` | Identifier that appears in issued tokens. |
| `authorization_endpoint` | Endpoint that starts sign-in. |
| `token_endpoint` | Endpoint that exchanges codes and refresh tokens. |
| `userinfo_endpoint` | Endpoint that returns user claims. |
| `jwks_uri` | Endpoint that returns signing keys. |
| `end_session_endpoint` | Endpoint that starts provider logout. |
| `scopes_supported` | Scopes the provider advertises. |
| `claims_supported` | Claims the provider advertises. |

## Example response

```json
{
  "issuer": "https://oidcproject-production.up.railway.app",
  "authorization_endpoint": "https://oidcproject-production.up.railway.app/o/authenticate",
  "userinfo_endpoint": "https://oidcproject-production.up.railway.app/o/userinfo",
  "jwks_uri": "https://oidcproject-production.up.railway.app/.well-known/jwks.json",
  "token_endpoint": "https://oidcproject-production.up.railway.app/o/token"
}
```
